# Многоплоскостной синтез фазовых голограмм

Четыре целевых изображения, одна фазовая маска. Сравниваем классические алгоритмы, готовую физическую нейросеть и оптимизацию под текущую четвёрку без предварительного обучающего корпуса.

**Авторы:** Nikolai Pautov, Miroslav Makarov, Timofey Rumeev, Maxim Kulyamin.

[Статья](article.pdf) · [Презентация](presentation.pdf)

## Задача

На вход поступают четыре полутоновых PNG размером 128 × 128. Требуется синтезировать фазовую маску такого же размера, которая формирует соответствующие изображения на расстояниях **24.1, 25.3, 26.5 и 27.7 мм**.

Длина волны — **532 нм**, шаг пикселя модулятора — **10 мкм**. Прямую задачу считаем методом Френеля с одним FFT на плоскость. Маска сохраняется в 8-битный PNG: `0` соответствует `−π`, `255` — `+π`.
